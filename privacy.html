Avi — Privacy policy

Last updated: 27 October 2026

Avi is a private assistant used only by its owner. It is not available to the public.

What Avi accesses

  • Google Gmail and Google Calendar data of the owner's own accounts, only after the owner signs in and grants access.
  • For the owner's personal account, access is read-only.

How the data is used

  • Only to help the owner: summaries, agendas, search, and drafts the owner reviews.
  • Avi never sends mail, accepts invitations or changes events without the owner's explicit approval each time.

Where the data is kept

  • On the owner's own computer. Access tokens are stored locally with restricted file permissions.
  • Requests are processed by the AI model the owner uses (Anthropic's Claude) to produce answers for the owner.

Sharing

  • Data is never sold, shared with third parties, or used for advertising.
  • Avi's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, after which locally stored tokens stop working and can be deleted.
